# Arangetram Adversaries — Master Challenge Archive

Nine standing adversaries, TIERED. The tier is an instruction, not a
suggestion: a wall attacked out of order is theater. Each adversary is a
self-contained folder with a SPEC (what it attacks, why it's load-bearing,
falsifiable pass criteria) and, where a schema/harness is needed, the files.

## Tiering — read this first
- **TIER 0 · GATES (minutes, non-negotiable, predate all specimens):**
  witness CI green once; confirm IP clearance. No adversary below counts until
  these are green. They are here because they are still open.
- **TIER 1 · LOAD-BEARING (attack now — these ARE the product):**
  A1 emit-determinism · A2 hostile-schema · A3 emit-roundtrip.
  Each guards a wall the venture is standing on or advertising as strongest.
- **TIER 2 · REAL, BUT SEQUENCED (after Tier 1 holds):**
  A4 collation · A5 pg-version-skew · A6 scale.
  Genuine walls; attacking them before Tier 1 is the meta-trap.
- **TIER 3 · BEYOND CODE (people & thesis — cheapest and most avoided):**
  A7 human-gauntlet · A8 banyan-bench · A9 silent-schema-market.

## The finish line (not "done" — "covered")
Every clause of the constitution has a standing adversary that has been
ATTACKED AND HELD. Track it as a table in the repo README. Today: introspect
soundness/completeness/taxonomy/optimizer/drift = held; everything in this
archive = not yet attacked. Half the walls. This archive is the other half.

## Anti-strip-mining rule
If you find yourself building A4 (collation is interesting!) while A1
(determinism is boring!) is unbuilt, stop. That impulse is exactly the
failure mode CanonFlow's constitution exists to prevent. Tier order or it's
theater.
