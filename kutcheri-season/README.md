# Kutcheri Season (Carnatic Music Festival)

This sample demonstrates CanonFlow's ability to parse complex textual and capacity boundaries.

### Key Learnings
- **String Range Parsing**: Translating `CHECK (slot IN ('MORNING', 'AFTERNOON', 'EVENING'))` into TypeScript literal unions.
- **Scale Constraints**: Bounding the `audience_capacity` structurally so that the frontend UI automatically validates maximum hall limits.
- **Regex Detection**: Translating standard SQL string length and format checks into Zod regex boundaries.
